BackupLens portable (Windows x64)
================================

Run BackupLens.exe from this folder. No installer or administrator rights are required.
The app opens the token URL in your browser; the console window can be closed with the
hamburger menu > Quit BackupLens.

Data and settings are stored in %LOCALAPPDATA%\BackupLens. The folder can be moved or
deleted safely; delete the data folder too if you want a fully clean reset.

This build is unsigned, so Windows SmartScreen may show a warning. Use "More info" >
"Run anyway" only if you downloaded it from the official GitHub release and verified
SHA256SUMS.txt.

BackupLens is not affiliated with Apple. Use it only on backups of devices you own or
are authorised to access.
